## Состав репозитория

Исходная тестовая папка содержит локальные CSV/XLSX в exports и временный sql/temp.sql. В корне тестовой папки нет собственного .git. Аудит первого коммита проводится в новой чистой копии. Приватные данные, выгрузки, дампы, архивы и временные файлы исключены из комплекта. Проверяются также необходимые файлы, которые правила Git должны пропускать.

Сканирование текстов ищет явные секреты, email, IP вне loopback и телефоны в строковых литералах. Контроль исторического снимка содержит технические ID исключений и остаточные суммы. Они нужны для сверки с приватным источником. Клиентские строки и таблицы соответствия в комплект не входят.

Техническая приёмка завершена. Адаптация публичных имён и решение о публикации остаются отдельным этапом. Переименование, коммит, push и публикация в ходе подготовки комплекта не выполнялись.
